# FastVoice documentation

The product documentation is written in MDX and is also indexed by the
FastVoice MCP documentation tools. Start with:

- `getting-started/` for installation and first-agent guidance;
- `voice-agent/` for workflows, testing, models, and embeds;
- `telephony/` for inbound/outbound providers;
- `integrations/` for MCP and external systems;
- `sdks/` for the Python SDK;
- `contribution/` for local development.

The live application exposes OpenAPI documentation at `/api/v1/docs`.
