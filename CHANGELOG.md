# Changelog

## 0.1.0 — 2026-08-15

- Imported the Dograh Python backend at revision
  `66ab884d5e4098d37beef7bc502a422ef42951ee` with BSD attribution.
- Added the FastVoice landing page, local authentication, and Google OpenID
  Connect authentication.
- Added the FastHTML application shell and data-backed operational views.
- Added the browser-native workflow canvas, spec-driven property editor,
  transitions, draft saving, and publishing.
- Replaced the external workflow-code validator with a safe Python AST bridge.
- Renamed and retained the typed Python SDK and runnable Python examples.
- Unified the public site, application pages, REST API, MCP server, static
  assets, and WebSockets in one Python application image.
- Added xAI realtime, language-model, and speech credential verification.
- Added Coolify-oriented production configuration for `voice.fastsme.com`.

For history before the FastVoice port, see the
[Dograh changelog](https://github.com/dograh-hq/dograh/blob/main/CHANGELOG.md).
